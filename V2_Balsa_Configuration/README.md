# V2 Balsa Configuration

V1 established the preliminary aerodynamic and stability configuration. V2 updates the design for balsa construction, measured hardware, a revised mass and CG estimate, and a new propulsion combination. The switch from CR001SM to a standard NACA section makes rib geometry easier to reproduce in balsa.

The [2D airfoil trade study](03_Aerodynamics/Airfoil_Trade_Study/Airfoil_Trade_Study.md) is the first completed analysis documented here. NACA 4412 is the first candidate for the 3D wing model, with NACA 2412 as the reference for comparing trim and drag.
