# Center of Gravity

Use the front firewall as x = 0, with x increasing aft. The rectangular wing has a mean aerodynamic chord (MAC) of 238 mm and a leading edge at x = 220 mm.

| Quantity | Value | Basis |
| --- | --- | --- |
| Initial target | 303.3 mm | 220 mm + 0.35 × 238 mm |
| Placement model estimate | 302.1 mm | Preliminary result reported in handoff |
| Difference | 1.2 mm forward of target | 303.3 mm − 302.1 mm |

The target gives a starting point for the V2 stability model. Compute the CG of any component layout as the sum of each component mass times its station divided by total mass. Moving a component aft shifts CG aft and reduces static margin for a fixed neutral point.

Validate the target using the V2 neutral point and trim results. Recalculate the CG using the component stations for the final radio configuration and check it on the assembled aircraft.
