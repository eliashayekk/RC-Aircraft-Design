# CAD

The fuselage baseline is 900 mm long and approximately 90 mm wide, with straight vertical sides, a Cessna-style silhouette, a high-wing saddle, a tractor motor and battery access. The front firewall is the x = 0 datum. The wing runs from x = 220 to 458 mm, the preliminary CG target is x = 303.3 mm, and the horizontal-tail leading edge is approximately x = 820 mm.

Use these stations in SolidWorks to check fit, balance and access. Resolve the wing saddle, removable mount, battery tray and final control linkages after the aerodynamic and stability decisions. Moving major components or aerodynamic surfaces changes mass moments or aerodynamic lever arms and requires updating the corresponding analysis.
