# V1 Airfoil Selection Study

This folder contains the V1 wing-airfoil comparison and its generated outputs.

## Run the Python analysis

Run `analyze_polars.py` with the working directory set to this folder. The script expects XFLR5 polar text files in `data/` and writes `airfoil_summary.csv` and `airfoil_analysis.xlsx` into this folder.

The script remains inside V1 because its current paths and generated outputs are coupled to this archived study.
