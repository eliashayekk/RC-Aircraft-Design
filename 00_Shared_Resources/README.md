# Shared Resources

This folder contains reference geometry that may be used by more than one design version.

## Contents

- `Airfoils/Wing_Candidates`: candidate wing-airfoil coordinate files
- `Airfoils/Tail_Candidates`: candidate tail-airfoil coordinate files

The analysis scripts remain beside their V1 datasets because their current file paths, outputs, and assumptions are tied to those studies. They can be refactored into shared tools later without changing the archived V1 files.
