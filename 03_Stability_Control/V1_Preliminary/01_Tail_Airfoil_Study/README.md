# V1 Tail Airfoil Study

This folder contains the V1 horizontal-tail airfoil comparison.

Run `analyze_tail_polars.py` from this folder. The script reads `raw_polars/` and writes `tail_airfoil_summary.csv` and `Tail_Airfoil_Analysis.xlsx` beside the script.

The script remains inside V1 because its paths and outputs are coupled to this archived study.
